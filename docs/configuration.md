# 設定ガイド

plsr-taskmasterの設定は、**実行ディレクトリ**の `package.json` にある `plsr-task` プロパティで行います。
(やらなくても動きます。)

```json
{
  "plsr-task": {
    "task-dir": "tasks",
    "template": "templates/plan-template.md"
  }
}
```

| キー | 型 | デフォルト | 説明 |
|------|-----|-----------|------|
| `task-dir` | string | `"tasks"` | タスクファイルを置くディレクトリ（実行ディレクトリからの相対パス） |
| `template` | string | （内蔵デフォルト） | createで使うplan雛形のテンプレートファイルパス |

`package.json` が存在しない場合や `plsr-task` プロパティがない場合は、すべてデフォルト値で動作します。

---

## planテンプレートのカスタマイズ

`template` にテンプレートファイルのパス（`package.json` からの相対または絶対）を指定すると、`ptm create` で生成されるplanファイルの雛形を差し替えられます。

### プレースホルダ

テンプレート内では以下のプレースホルダが使えます。

| プレースホルダ | 置換内容 |
|---------------|---------|
| `{{taskName}}` | タスク名 |
| `{{date}}` | 作成日（yyyy-MM-dd形式） |

`{{未知の名前}}` は置換されずそのまま残ります（Markdown内で `{{...}}` 記法を使っていても壊れません）。

### テンプレート例

`templates/plan-template.md`:

```markdown
# {{taskName}} ({{date}})

## 背景
なぜこのタスクが必要かを書いてください。

## ゴール
完了条件を書いてください。

## 指示内容
具体的な指示を書いてください。

## 実行結果
ここに実行結果を書いてください。
```

### フォールバック仕様

テンプレートが使えない状況でも `create` は失敗せず、警告を表示して内蔵デフォルトの雛形で作成します。

| 状況 | 挙動 |
|------|------|
| `template` 未設定 | 内蔵デフォルトを使用（警告なし） |
| ファイルが存在しない | 警告 + 内蔵デフォルト |
| パスがディレクトリ | 警告 + 内蔵デフォルト |
| 読み込みエラー（権限等） | 警告 + 内蔵デフォルト |
| 内容が空・空白のみ | 警告 + 内蔵デフォルト |

## ディレクトリ構造

設定した `task-dir` の中は以下のように使われます。

```
tasks/
├── plan.taskA.1.md          # 実行中タスクのplanファイル
├── review.taskA.1.md        # 実行中タスクのreviewファイル
├── stash/                   # 退避されたタスク
│   └── taskB/
│       └── plan.taskB.1.md
├── done.2026-07-16/         # 完了タスクのアーカイブ（日付ごと）
│   └── taskC/
│       ├── plan.taskC.1.md
│       └── review.taskC.1.md
└── ...
```

ファイル命名規則:

- planファイル: `plan.<タスク名>.<サイクル番号>.md`
- reviewファイル: `review.<タスク名>.<サイクル番号>.md`
- サイクル番号は1始まりの整数
